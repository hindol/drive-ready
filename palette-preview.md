# DriveReady Palette Preview

These options are **less muted** (more contrast + a clearer accent) while staying “not neon”.

Each palette is mapped to the tokens used in `src/index.css`:
- `--driveready-primary`
- `--driveready-primary-dark`
- `--driveready-primary-soft`
- `--driveready-primary-pressed`
- `--driveready-secondary`
- `--driveready-accent`
- `--driveready-primary-muted`
- `--driveready-focus-ring`

Open this file in VS Code’s Markdown preview to see swatches.

## Applying a palette

1) Update the variables in `src/index.css`.

2) Update the hero gradient + any hard-coded `rgba(r, g, b, …)` in `src/App.css` to match the chosen palette’s RGBs.

If you tell me which option (A–E) you want, I can apply it across the app in one patch.
