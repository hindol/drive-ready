# DriveReady User Guide

This guide walks through the primary learner flows inside DriveReady using fresh screenshots generated via the Playwright E2E suite. Each section includes concrete steps plus a visual reference so testers, copywriters, and contributors can mirror the exact UI state.

> **Tip:** All screenshots live in `docs/screenshots/` and can be regenerated by running `npx playwright test --project=chromium`.

## 1. Landing overview & navigation

1. Load https://hindol.github.io/drive-ready/.
2. Review the Washington-focused hero, stats, and onboarding card.
3. Use the navbar anchors (Overview, Mock Test, Review, Checklist) or the GitHub mark on the far right to explore the source repo in a new tab.

![DriveReady landing hero showing Washington overview and Start Practicing CTA.](./screenshots/landing-hero.png)

## 2. Taking a Mock Knowledge Test

1. Click **Start Mock Test** in the hero card.
2. Read each prompt, select an answer, and review the explanation plus Washington Driver Guide citation.
3. Use **Save & Next** (or **Finish Test** on the final question) to advance.

![Mock test question showing answer feedback and explanation drawer.](./screenshots/mock-test-question.png)

## 3. Tracking the Daily 10-question habit

1. After answering a question, scroll to the Daily habit card in the sidebar.
2. Watch the progress bar fill toward the practice goal (defaults to 10 questions).
3. Maintain streaks by meeting the goal each day; the calendar highlights today, past misses, and future dates.

![Daily habit card showing progress against the 10-question goal.](./screenshots/habit-card.png)

## 4. Running Smart Review

1. Scroll to the **Smart Review** section and click **Start Smart Review**.
2. Select an answer to reveal the explanation and citation.
3. Rate each card (Again/Hard/Good/Easy) to schedule the next review.

![Smart Review card after revealing the explanation and rating options.](./screenshots/smart-review.png)

## 5. Resetting progress

1. Click **Reset Progress** in the sidebar.
2. Confirm you understand the warning (mock test history, practice streaks, and Smart Review data will be wiped on this device).
3. Choose **Erase everything** to start over, or **Cancel** to keep your data.

![Reset confirmation modal warning that the action clears all saved progress.](./screenshots/reset-modal.png)

## Regenerating screenshots

Whenever the UI changes, rerun the Chromium-only Playwright suite to refresh every image referenced above:

```bash
npx playwright test --project=chromium
```

The helper in `tests/utils/doc-screenshots.ts` ensures screenshots only save once per run, and they’re committed under `docs/screenshots/` for easy documentation updates.
