# DriveReady Theme Palette Explorer

Preview muted blue palettes directly inside VS Code (open this file in the Markdown preview panel to see the swatches).

## How to read the swatches
- **Primary**: Main brand/nav color — used for hero backgrounds, buttons, and footer.
- **Secondary**: Supporting accents — suitable for cards, highlights, and gradients.
- **Accent**: Light neutrals — ideal for subtle backgrounds and info badges.

### Tips
- Copy the hex codes into `src/index.css` (`--driveready-primary` etc.) when you pick a palette.
- Re-run `npm run build` and spot-check the hero, navbar, buttons, and Smart Review controls after applying a new scheme.
- Update this file if you introduce more palettes so everyone has a visual reference.
